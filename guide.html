    看完整說明 ↓
    這裡是教學用示範畫布。要修改自己的 HTML，請按頁面右上角「開啟編輯器」。
    可搜尋以下所有章節
    00

    開始使用

    第一次開啟，先照這四步操作。

    1雙擊開啟 HTML編輯器.html。
    2把本機 HTML 拖進編輯器或畫布，也可點「開啟檔案」選檔。
    3在畫布點選文字或左側選一組樣式，完成修改。
    4按「另存 HTML」，確認實際存檔或下載狀態。
    如果報表的圖片、CSS 沒顯示，先到左側「素材 → 加入資料夾」載入整個素材資料夾，再選其中的 HTML。
    01

    上方｜檔案與儲存

    頂端深綠色品牌旁的檔名、存檔訊息與右側按鈕。

    開啟檔案拖入一份 .html／.htm 即可編輯，多份會加入批次。拖曳時放置區中央會顯示「放開以匯入檔案」，也可按「開啟檔案」選檔。開啟另一份前，若目前有未存修改，會先提醒。重新開啟編輯器若找到上次草稿，頂端會出現「恢復草稿／略過」；素材仍需重新載入。
    另存 HTML在支援檔案存取的 Chrome／Edge 中，可挑選位置與檔名；其他環境會送出下載副本。Ctrl+S 也會執行另存。
    右側更多選項包含「覆寫目前檔案」「下載 HTML 副本」「複製 HTML 原始碼」。覆寫只在編輯器持有可寫入的檔案權限時可用。
    檔名下方訊息明確區分「副本下載已送出」「已另存檔案」「已寫回目前檔案」，並顯示檔名與時間。下載已送出時，仍須到瀏覽器下載清單確認完成。
    「下載副本」不會覆寫原檔。改完之後即使按過復原，磁碟檔案也不會跟著回退；要更新磁碟，請再存一次。
    02

    上方｜復原、搜尋與模式

    第二排工具列是日常編輯最常碰到的控制。

    復原／重做

    按左箭頭復原、右箭頭重做；也可用 Ctrl+Z、Ctrl+Shift+Z 或 Ctrl+Y。存檔後同一工作階段仍可復原。

    搜尋與取代

    放大鏡或 Ctrl+F 開啟單檔搜尋。可找下一處、取代這一處或全部取代；可選擇是否區分英文大小寫。只處理 HTML 文字。

    視覺編輯

    看到報表原本的版型，可點選或直接修改原有 HTML 文字、區塊、圖片及樣式。編輯時暫停原報表的 JavaScript，避免程式把修改沖掉。

    互動預覽

    在隔離畫面執行原報表程式，測試圖表、按鈕和分頁。此模式供檢查互動，不提供直接修改；報表本身可能連線讀取資源。

    原始碼

    需要進階修改時可查看與編輯 HTML。按「套用並預覽」返回畫布。只打開查看不會改掉原文或 Windows 換行；一般改字不需要用這個模式。

    03

    上方｜展開全部、還原檢視

    整份報表的檢視操作放上方，不另占一個頁面工作欄。

    • 「展開全部」暫時打開 details 與有明確控制關係的收合段落，再按一次還原收合狀態。沒有可展開內容時按鈕停用。
    • 不會一起打開互斥頁籤、選單或彈窗。報表原有頁籤可直接在畫布點選；按「還原檢視」回到原始顯示。
    • 特定隱藏區塊在「圖層 → 隱藏與可切換內容」定位。這些檢視操作不改寫匯出 HTML 的預設狀態。
    04

    左側｜文件結構

    用階層清單管理報表原有區塊、圖片與表格。

    展開「文件結構」，在樹狀清單點某個項目，畫布就會選到對應位置。這相當於報表的簡化圖層清單；它顯示 HTML 元素階層，不會任意重組原始結構。

    選到區塊後，物件旁會浮出區塊工具

    複製／剪下／貼上複製或移走選取區塊，再貼到所選區塊後方。沒有複製區塊時，貼上可新增一個純文字段落。
    建立副本在後方複製一份區塊；副本內的 ID 與對應引用會更新，避免與原區塊衝突。
    上移／下移／上層／刪除調整同層順序、選外層容器或刪除整個區塊。可用復原找回。
    表格工具選中規則表格的儲存格後，可加／刪列欄、切換表頭、調整對齊及列底色。

    選到區塊且沒有正在編輯文字時，也可用 Ctrl+C、Ctrl+X、Ctrl+V 和 Delete 操作區塊。

    含腳本、iframe、Canvas 等互動內容的區塊不提供結構複製；合併儲存格或不規則表格會拒絕結構增刪，避免破壞版型。
    05

    左側｜圖片工具

    選取一般圖片後才出現。

    更換圖片與來源

    按「選擇新圖片」挑本機圖片，會嵌入輸出 HTML；也可直接改來源路徑或網址。未修改的圖片仍保留原路徑。

    替代文字

    在「替代文字」填寫圖片內容描述；圖片載入失敗及輔助閱讀時也能使用。

    大小與比例

    輸入寬高 px，或用數值拖曳／滾輪快速調整。「鎖定長寬比例」可維持原本比例。

    顯示方式與焦點

    可選完整顯示、填滿並裁切、拉伸、原尺寸或縮小符合；水平／垂直焦點用百分比指定裁切中心。

    「填滿並裁切」只改在頁面上的顯示範圍，不修改原圖像素。新圖片內嵌後，HTML 檔案可能變大。
    06

    左側｜素材與可編輯性檢查

    幫你判斷「為什麼報表跟原來看起來不一樣」。

    展開後可查看圖片來源及缺失、相對素材、外部 CSS、CSS 背景圖片、字體宣告、CSS 變數、內嵌 SVG、Canvas 與腳本。可點圖片項目定位畫布；下方可重新載入素材資料夾。

    圖片／CSS 缺失先載入包含 HTML、圖片與 CSS 的整個資料夾，讓相對路徑能找到檔案。
    字體會列出宣告名稱，但無法保證你這台電腦已安裝或外部字體已成功載入。
    SVG／Canvas原有 SVG 文字可在可辨識時編輯；Canvas 畫面中的文字是程式繪製，不能直接點字修改。
    腳本診斷不會在編輯模式執行原報表腳本；要測動態功能，切換互動預覽。
    07

    左側｜文件共用樣式

    先決定改一個、改同樣式，還是改整份文件。

    單一

    只改目前選取的文字或元素；適合例外樣式。

    同樣式

    把原本設定相同的元素選成一組，再一起修改。

    全文件

    在目前樣式工具的適用範圍中，對整份報表修改。

    群組選取與提示

    • 選一組後會短暫亮出成員外框。「顯示這組」重播、「保持細框」持續標示、「下一處」逐一定位。標記是編輯器覆蓋層，不影響報表版型，也不寫入輸出。
    • 展開「這組有哪些元素」可看數量、只在本次工作階段有效的臨時命名、依區域篩選、是否包含隱藏分頁，並排除不想一起修改的成員。
    • 「重新掃描」依目前類別重建群組。「選上層」可從文字改選外層卡片；「樣式來源」提示設定來自元素本身、樣式表或繼承。
    群組按目前顯示出來的樣式判斷，可能跨越不同標籤或 class。修改後原群組範圍會固定，避免下一次調整意外擴大到別的元素。
    08

    左側｜六種樣式工具

    六個圖示與文字常駐側欄上方，直接點選類別。

    Aa

    字體

    按字體與字級分組。可統一字體、字級、行距；可搜尋、查看近期字體或指定其他字體。字體選單移入即預覽、移出取消、點選套用。

    A

    文字色

    依實際文字顏色分組。可用色票、近期／文件色、色碼與透明度；可整組或單一調整。

    ◈

    背景

    可調底色、背景圖或漸層、尺寸、位置與重複方式；可用透明色或移除背景圖層。

    ↕

    間距

    可選內距、外距或 Gap。四邊能連動或分別輸入；Gap 分行、列兩個方向。

    □

    框線

    可調四邊寬度、線條樣式與顏色，支援連動四邊或個別調整。

    ◜

    圓角

    可統一四角，也可分開調每一角；適合卡片、按鈕與表格容器。

    顏色與數值怎麼套用

    色票在支援的欄位會即時更新；手輸色碼或其他屬性後，按 Enter 或離開欄位即套用。只套用本次改過的欄位，其他設定保留。透明／零值元素預設可能略過，可勾「也列出透明／零值樣式」。

    數字旁的 ↔ 可左右拖曳；點進數字欄位後可滾輪調整。未聚焦時滾輪只捲動側欄，以免誤改；Alt+滾輪 可直接調指向欄位。Shift 加速，Alt 細調；方向鍵亦可調。Esc 取消這段調整，連續拖曳或滾輪合併為一次復原。

    整篇只改字體時，原本標題與正文的字級會保留；若對全文件改字級，所有適用文字會採新字級。響應式 CSS、auto、calc() 或變數不會被擅自換算成零。
    09

    內容｜直接在畫布改字

    點選物件後，「編輯」直接提供相關工具。

    在「編輯 → 字體」下，點選頁面上的文字就能直接輸入。其他樣式工具下可雙擊文字修改。按 Enter 完成、Esc 取消這次輸入；儲存時把修改寫回原 HTML 對應位置。

    左側不會再列出偵測片段讓你重選。點圖片時顯示換圖、尺寸與裁切設定。SVG 文字或下拉選項等無法原位輸入的特殊元素，才會開啟替代文字欄。

    字體、字級、粗斜體、底線與對齊在同一套控制中調整，可選單一、同樣式或全文件。

    10

    批次｜改一份，選修改同步

    先選好檔案；不用輸入同一段搜尋取代。

    1. 直接把 HTML 拖入批次側欄，或按「加入 HTML」選檔。
    2. 點檔名在畫布編輯。切換檔案保留各檔修改與復原紀錄；這些內容只保留於本次工作階段。
    3. 回到來源檔，按「選擇修改並同步…」。勾選要同步的文字、字體、顏色、間距、框線、圖片等修改，再勾選目標檔案。
    4. 按「預覽差異」：逐檔顯示原本／修改後、已相同或略過原因。對應不明、原文或個別樣式不符時保留目標原值。可展開完整 HTML 前後內容。
    5. 按「匯出 ZIP」。修改副本、原檔備份和結果清單一併下載，不覆寫原檔；來源檔完整副本可自行取消勾選。

    目前同步文字、可辨識的樣式與圖片來源／替代文字。以唯一識別位置優先，無識別位置時要求相同版型結構；區塊增刪移動和程式修改不自動同步。相對圖片路徑需先以新圖片內嵌，避免其他檔案找不到圖。

    單檔上限 25 MB、整批 100 MB。修改副本統一 UTF-8；原檔備份保留原始位元組。外部 CSS、圖片仍需保留原有相對位置。匯出後，目標檔在畫布的內容不會被預覽覆寫；重新加入下載副本可繼續編輯。
    11

    存檔選單｜修改紀錄與版本

    按「另存 HTML」旁的箭頭，選「修改紀錄與版本」。

    修改清單列出目前局部修改，可按「回復這項」移除單項補丁；該回復本身也能再按復原找回。區塊結構調整可用上方復原。
    建立瀏覽器快照把目前文件內容存入這個瀏覽器。每份文件最多 8 版、每版約 2 MB；容量不足會提示另存檔案。
    比較／回復比較顯示和目前畫布的首個差異及片段。回復後只改畫布，可再用復原找回回復前的編輯。
    匯出／刪除／清除單版可匯出 HTML，全部可匯出 ZIP；也可刪某版或清除這份文件的快照。
    清除瀏覽資料、無痕模式或換瀏覽器，都可能失去快照。回復快照後若要改到磁碟，仍需按「另存 HTML」或在有權限時覆寫。
    12

    素材｜直接看圖與替換

    左側「素材」就是直接入口，圖片不藏在檢查工具裡。

    • 「報表中的圖片」顯示縮圖、檔名與來源狀態。點「定位」選到畫布圖片；點「替換」選擇本機新圖片。
    • 「加入圖片」可多選圖片，先放入素材庫。選取畫布圖片後，在素材庫按「替換選取圖片」；套用後以內嵌圖片保存。
    • 「加入資料夾」讀取報表引用的相對路徑素材，CSS 和字體等資源也列在素材庫。單純加入素材不會插入新的圖片元素。
    • 「資源狀態」收合區補充缺圖、外部 CSS 和特殊內容的狀態。最近檔案與範例改放「拖入 HTML」旁選單；搜尋、說明仍在上方。
    13

    中央｜報表畫布

    畫布顯示原報表版型，是主要操作區。

    • 在「編輯 → 字體」下，點畫布文字即可直接打字；其他樣式工具下可雙擊改字。一般文字不必到左側編輯片段；點圖片則顯示圖片工具。選到區塊時，物件旁會浮出複製、剪下、貼上、上移、下移等操作，優先放在物件上方，空間不足時換邊，並隨捲動與縮放定位；選中表格格子還會顯示表格工具。
    • 畫布右上角切換桌面／手機寬度，用百分比選單縮放。重新載入按鈕可重畫目前畫布，方便檢查。
    • 手機寬度及縮放只改編輯器預覽，不直接改輸出 HTML。匯出時仍保留報表原本的樣式規則。
    • 群組提示是畫布上方的獨立外框，不會把閃爍或細框存到報表裡。
    14

    底部｜狀態與保存層級

    讀狀態時，先分清楚這三種保存位置。

    工作階段復原

    當前分頁內的操作歷史。存檔後仍能復原，但關閉後不保證保留。

    瀏覽器草稿／快照

    存在目前瀏覽器，幫忙恢復未存內容與版本；不等於磁碟檔案。

    磁碟存檔／下載

    按另存、覆寫或下載後才產生實際檔案；下載要看瀏覽器清單確認。

    底部狀態列會顯示「準備好了」、修改數量及草稿提示。頂端檔名旁的小圓點與存檔訊息用來判斷現在是否還有待存修改；操作失敗或取消時也會提示原因。

    15

    適用範圍與限制

    知道哪些修改可靠，才能放心用在正式報表。

    • 適合：本機靜態 HTML 報表的錯字、原有文字、共用或個別樣式、圖片來源、規則表格及原有區塊結構。
    • 局部保留：一般文字與樣式修改優先對原始 HTML 的對應位置下手；未改的腳本、註解、素材路徑與其他區段會保留。需要時可用原始碼模式處理進階情況。
    • 需要原資料：JavaScript 動態產生的內容、Canvas 繪圖文字、圖片像素內文字、CSS 偽元素文字、伺服器資料，都不能保證在畫布直接改到來源。
    • 素材與連線：工具本身不會自動上傳報表，也可離線開啟；原報表引用的外部資源或互動預覽中的程式可能連網。另存後保留相對素材路徑時，請讓素材資料夾結構跟著檔案一起保留。
    • 編碼：可匯入 UTF-8、UTF-16 與常見宣告編碼；未宣告且非 UTF-8 會嘗試 Big5。一般另存輸出 UTF-8，並更新或補上編碼宣告。
    最穩妥的正式流程：先複製或另存一份 HTML → 編輯 → 到「互動預覽」檢查 → 下載或存檔 → 重新開啟輸出檔核對。

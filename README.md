# HTML Editor｜紙上 Paper

用瀏覽器直接編輯 HTML 報表的文字、樣式和圖片。適合在保留既有版型與程式的情況下修訂報表，或把同一筆修改同步到多份檔案。

**[開啟線上編輯器](https://eason-6113.github.io/HTML-Editor/)** · [操作手冊](https://eason-6113.github.io/HTML-Editor/guide.html) · [下載離線版](https://github.com/eason-6113/HTML-Editor/releases/latest)

## 開始使用

1. 用 Chrome 或 Edge 開啟編輯器，把本機 HTML 報表拖進上方匯入區或畫布。一次拖入多份會進入批次，圖片會加入素材庫。也可點「拖入 HTML」選檔。
2. 在畫布點選文字或圖片，直接修改內容，也可以在側欄選擇單一元素或共用樣式群組調整外觀。
3. 按「另存 HTML」取得修改後的副本。多份報表可用「批次」選擇要同步的修改，核對逐檔差異後匯出 ZIP。

| 功能 | 操作 |
|---|---|
| 視覺編輯 | 修改文字、圖片、字型、顏色和版面樣式 |
| 文件導覽 | 展開可辨識的收合段落、定位圖層及還原檢視 |
| 批次同步 | 選擇來源修改與目標檔案，預覽差異及衝突 |
| 本機保存 | 下載 HTML，或匯出附原檔備份的 ZIP |

編輯器在瀏覽器內處理你選取的檔案。若報表引用外部素材，瀏覽器可能依報表設定載入。請用虛構資料重現公開回報中的問題。

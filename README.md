# 紙上 Paper HTML 編輯器

[開啟編輯器](https://eason-6113.github.io/paper-html-editor/) · [操作說明](https://eason-6113.github.io/paper-html-editor/guide.html)

在瀏覽器開啟本機 HTML 報表，編輯文字、樣式與圖片。多份報表可先預覽同步差異，再匯出 ZIP。編輯器在瀏覽器內處理選取的檔案，也可下載 index.html 直接離線開啟。

發佈時從本機專案主檔 HTML編輯器.html 更新 index.html，從完整功能說明更新 guide.html。GitHub Pages 以 main 分支根目錄發佈。
